# Security

Report security issues privately through GitHub's private vulnerability reporting when enabled. Do not include secrets or transcripts in a public issue.

Insomnia runs as the current user. It does not require sudo, change persistent pmset configuration, send telemetry or make network requests. Optional agent connections modify user-level configuration after the user chooses Connect; existing configurations are backed up. The lifecycle bridge retains only agent name, session identifier, state and timestamp. It never approves agent permission requests.

Accessibility enables a screen-lock shortcut. Input Monitoring enables Fn detection. Both permissions are optional and controlled in System Settings. The separate power helper releases ownership on normal stop, EOF, parent loss, heartbeat timeout and termination; a stale receipt is recovered on the next launch. Closed-lid control uses a private macOS interface and is experimental.
